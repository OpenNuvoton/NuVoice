-------------
NuFrameEditor V1.00.000
-------------
[Features]
+ Import multiple image files (BMP, GIF, PNG, JPG) and manage them centrally in the Image Manager
+ Create multiple frames and place images into each frame with a specified position and stacking order (Z-order)
+ Preview the composed picture of all images in real time in the Frame View, and adjust positions by dragging
+ Save the finished project as an .nfd file
+ Export it to binary file as image data structure usable by firmware or a device
+ Provide sample code to illustrate its usage
